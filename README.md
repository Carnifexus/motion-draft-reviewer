# Motion Draft Reviewer

A reusable AI-assisted review workflow for lawyers who want a candid, source-grounded critique before filing. It starts with the order the draft actually asks the court to enter, then checks the legal standard, record support, the best opposition, and the practical fixes.

## Start here

1. Read the [Lawyer Guide](docs/LAWYER-GUIDE.md).
2. Load [SKILL.md](SKILL.md) into an approved AI workspace, or paste it as working instructions.
3. Provide the draft, proposed order, posture, governing authorities, and a limited record packet. Tell the reviewer which sources it may access and where to stop.
4. Ask for a review only. Verify every consequential finding yourself.

Try the workflow first with the [fictional input](examples/FICTIONAL-INPUT.md). The [illustrative output](examples/FICTIONAL-OUTPUT.md) shows how to separate a finding from an inference and what to do with an unresolved defect. The [White Paper](docs/WHITE-PAPER.md) explains the design and limits.

This repository contains instructions and examples, not an executable or a hosted service. It does not file, serve, email, or edit your draft. It is intended for licensed attorneys and provides no legal advice, warranty, assurance of privilege, indemnity, or defense. Use only an approved environment and verify the governing law, applicable bar guidance, and the accuracy of the underlying record.
